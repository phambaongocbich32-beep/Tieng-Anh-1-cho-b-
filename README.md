# Ôn Tập Tiếng Anh 1 (Global Success)

Web học tiếng Anh cho học sinh lớp 1. Không cần cài đặt hay build, chỉ cần các file tĩnh.

## Đưa lên GitHub Pages
1. Tạo repository mới trên GitHub (ví dụ `on-tap-tieng-anh-1`).
2. Tải toàn bộ nội dung thư mục này lên repository (index.html nằm ở thư mục gốc).
   Nếu kéo thả trên web bị giới hạn 100 file mỗi lần, hãy tải làm 2 đợt (một đợt thư mục `ws`, một đợt phần còn lại) hoặc dùng GitHub Desktop / git.
3. Vào Settings > Pages > Build and deployment, chọn Source: Deploy from a branch, Branch: main, thư mục / (root), rồi Save.
4. Sau 1–2 phút mở: https://TEN-TAI-KHOAN.github.io/TEN-REPO/

Nên mở bằng Chrome hoặc Edge để có giọng đọc nữ Anh-Mỹ.
